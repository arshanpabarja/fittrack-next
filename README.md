# FitTrack Next

این پوشه نسخه مستقل نرم‌افزار پذیرش لایف‌باکس است. کد، محیط اجرا، سایت Django،
مدل‌های چهره و دیتابیس آن از نسخه قدیمی جدا هستند.

## اجرای برنامه

```powershell
cd "C:\Users\Arshan\Desktop\FitTrack Next"
.\.venv\Scripts\python.exe launch.py
```

برای اجرای برنامه از `start-fittrack-next.ps1` و برای اجرای سایت از
`start-django.ps1` استفاده کنید.

## اصول معماری

- `domain`: مدل‌های مستقل از رابط کاربری و دیتابیس
- `data`: تنها محل دسترسی مستقیم به SQLite
- `services`: قوانین و use caseهای برنامه
- `ui`: صفحات PyQt6 و workerهای غیرمسدودکننده
- دیتابیس نسخه جدید داخل همین پوشه قرار دارد.
- هیچ کوئری سنگینی روی ترد رابط کاربری اجرا نمی‌شود.
