# Life Box

این پوشه نسخه مستقل نرم‌افزار پذیرش لایف‌باکس است. کد، محیط اجرا، سایت Django،
مدل‌های چهره و دیتابیس آن از نسخه قدیمی جدا هستند.

## اجرای برنامه

```powershell
cd "C:\Users\Arshan\Desktop\FitTrack Next"
.\.venv\Scripts\python.exe launch.py
```

برای اجرای برنامه از `start-fittrack-next.ps1` و برای اجرای سایت از
`start-django.ps1` استفاده کنید.

کارتخوان واقعی شبکه‌ای فعال است؛ تنظیمات اتصال و راهنمای بررسی پرداخت در
[POS_TESTING.md](POS_TESTING.md) آمده است.

برنامه به‌صورت پیش‌فرض در حالت تمام‌صفحهٔ کیوسک اجرا می‌شود. برای توسعه و
اجرای پنجره‌ای، پیش از اجرا متغیر محیطی `FITTRACK_WINDOWED=1` را تنظیم کنید.

## اصول معماری

- `domain`: مدل‌های مستقل از رابط کاربری و دیتابیس
- `data`: تنها محل دسترسی مستقیم به SQLite
- `services`: قوانین و use caseهای برنامه
- `ui`: صفحات PyQt6 و workerهای غیرمسدودکننده
- دیتابیس باشگاه در پوشهٔ `database` کنار پوشهٔ برنامه قرار دارد؛ مسیر دلخواه با `FITTRACK_DATA_DIR` قابل تنظیم است.
- هیچ کوئری سنگینی روی ترد رابط کاربری اجرا نمی‌شود.

## انتقال به کامپیوتر دیگر

روی ویندوز Python 3.12 نسخه ۶۴ بیتی و Git نصب کنید، سپس:

```powershell
git clone https://github.com/arshanpabarja/fittrack-next.git
cd fittrack-next
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

برنامه را روی کامپیوتر مبدأ ببندید و پوشهٔ `database` باشگاه را با فلش یا شبکهٔ
خصوصی، کنار پوشهٔ `fittrack-next` در کامپیوتر مقصد کپی کنید. پوشهٔ `state` داخل
برنامه را نیز برای حفظ تنظیمات و سوابق نسخهٔ جدید منتقل کنید. اطلاعات اعضا و
چهره‌ها داخل گیت‌هاب قرار نمی‌گیرند. محیط `.venv` را از کامپیوتر قبلی کپی نکنید.

سپس اجرا کنید:

```powershell
.\.venv\Scripts\python.exe launch.py
```

برای مسیر دلخواه دیتابیس، پیش از اجرا `$env:FITTRACK_DATA_DIR = 'D:\Gym\database'`
را تنظیم کنید. در تنظیمات مدیر، آدرس API، دوربین‌ها و کارتخوان را متناسب با
کامپیوتر مقصد تنظیم کنید. برای کار با سرور فعلی، کامپیوتر مقصد باید به شبکهٔ
باشگاه دسترسی داشته باشد. مدل‌های چهره و درایور کارتخوان همراه مخزن هستند.

برای ساخت شورتکات، داخل پوشهٔ پروژه روی `create-desktop-shortcut.cmd` دوبار کلیک
کنید. شورتکات روی همان کامپیوتر برای پوشهٔ فعلی پروژه ساخته می‌شود و آیکون پروژه
را دارد. پس از انتقال یا تغییر نام پوشه دوباره آن را بسازید.
اگر برنامه اجرا نشد، خطای شروع در پنجره نمایش داده می‌شود و جزئیات آن در
`logs/startup-*.log` قرار می‌گیرد. پوشهٔ `.venv` کپی‌شده از کامپیوتر دیگر ممکن
است به پایتون همان کامپیوتر اشاره کند؛ محیط را طبق مراحل بالا روی مقصد بسازید.
برای اجرای مستقیم و مشاهدهٔ خطاها در پنجره‌ای که پس از خطا باز می‌ماند،
فایل `run-lifebox.cmd` را اجرا کنید.
